# Change: Build AI WorkPilot

## Why
컴퓨터공학 신입 지원자가 단순 챗봇이 아니라 계획 수립, 안전 승인, 도구 실행, 관측성, 실패 복구를 설계할 수 있음을 증명한다.

## What Changes
- 한국어 업무 요청을 구조화된 실행 계획으로 변환한다.
- 외부 부작용이 있는 단계는 서버 측 승인 상태 없이는 실행하지 않는다.
- 모든 실행은 `DEMO` 시뮬레이션이며 실제 외부 API를 호출하지 않는다.
- 실행과 승인 이벤트를 D1에 저장하고 세션 소유권으로 격리한다.
- 성공, 승인 거절, 실패 및 재시도 흐름을 한 화면에서 시연한다.

## Non-goals
- 실제 메일·캘린더·Slack 발송
- 실서비스 OAuth 및 조직 단위 권한 관리
- 특정 유료 LLM 의존 또는 AI 정확도 과장
